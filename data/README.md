# Dataset Documentation: TalentMatch ML Resumes & Job Descriptions

## Resume Corpus
The resume repository contains multi-format candidate profiles (`.docx`, `.txt`) covering varying seniorities:
- `candidate_01_lead_ml_engineer.docx`: Senior ML & MLOps Engineer (6.5 Yrs exp)
- `candidate_02_data_scientist.txt`: Mid-level Data Scientist (4.0 Yrs exp)
- `candidate_03_junior_ml_intern.txt`: Junior ML Intern (2.0 Yrs exp)
- `candidate_04_fullstack_lead.docx`: Lead Full Stack Engineer (7.0 Yrs exp)
- `candidate_05_frontend_dev.txt`: Frontend React Developer (3.0 Yrs exp)
- `candidate_06_devops_cloud_architect.docx`: Principal Cloud DevOps Architect (8.0 Yrs exp)
- `candidate_07_bi_data_analyst.txt`: BI & Data Analyst (4.5 Yrs exp)
- `candidate_08_java_backend_dev.txt`: Java Backend Developer (5.5 Yrs exp)

## Job Descriptions
Structured role specifications in JSON format:
- `job_senior_ml_engineer.json`
- `job_lead_fullstack_engineer.json`
- `job_cloud_devops_specialist.json`

Each job description explicitly defines mandatory core skills, nice-to-have preferred skills, minimum experience thresholds, and contextual text.
